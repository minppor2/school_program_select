## 캡처 방법

```bash
node scripts/stage-server.js 3001
```

캡처할 때는 `http://127.0.0.1:3001`로 접속합니다. `localhost`로 접속하면 3000번 서버의 로그인 쿠키를 덮어써 로그아웃됩니다.

임시 가상 학교에 모집 5개를 단계별(준비 / 접수 중 / 접수 마감 / 배정 검토 / 결과 공개)로 만들어 띄웁니다.
접속 정보는 `data/stage-info.json`에 적히며, 각 단계 화면을 한 번에 열어 캡처할 수 있습니다.

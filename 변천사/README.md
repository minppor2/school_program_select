# 변천사 — 화면이 바뀌어 온 기록

만들 때마다(기능을 더하거나 화면을 고칠 때마다) 주요 화면을 캡처해 버전 폴더로 남깁니다.
모든 캡처는 **가상 데이터**입니다.

| 버전 | 날짜 | 무엇이 달라졌나 |
| --- | --- | --- |
| [v01 첫 완성](v01_2026-11-12_첫완성) | 2026-11-12 | 인수인계 문서 기준 1차 MVP. 학생 QR 신청, 교사 개설·접수 확인·배정·공개·명단까지 처음으로 끝까지 동작 |

## 폴더·파일 이름 규칙

- 폴더: `v번호_날짜_한줄설명` (예: `v02_2026-11-20_결과정정추가`)
- 파일: `순번_누구_화면이름.jpg` — 버전끼리 같은 번호가 같은 화면이 되도록 유지합니다(새 화면은 뒤 번호로 추가).

| 번호 | 화면 |
| --- | --- |
| 01 | 교사 로그인 |
| 02 | 교사 모집 목록 |
| 03 | 교사 준비 — 지금 할 일 점검 |
| 04 | 교사 준비 — 프로그램·인원 설정 |
| 05 | 교사 접수 중 — 현황 |
| 06 | 교사 접수 중 — QR·미제출 명단 |
| 07 | 교사 접수 마감 — 배정하기 |
| 08 | 교사 배정 검토 — 검증 결과 |
| 09 | 교사 배정 검토 — 요약·명단 |
| 10 | 교사 결과 공개 |
| 11 | 학생 본인 확인 (휴대전화 크기) |
| 12 | 학생 희망 고르기 |
| 13 | 학생 접수 완료 |
| 14 | 학생 배정 결과 |

## 캡처 방법

```bash
node scripts/stage-server.js 3001
```

임시 가상 학교에 모집 5개를 단계별(준비 / 접수 중 / 접수 마감 / 배정 검토 / 결과 공개)로 만들어 띄웁니다.
접속 정보는 `data/stage-info.json`에 적히며, 각 단계 화면을 한 번에 열어 캡처할 수 있습니다.

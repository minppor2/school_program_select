## 채워야 하는 것

- 공급자 이름(실명)과 소속 학교, 문의 이메일
- 접속 주소, 처리방침을 볼 수 있는 주소
- 보유 기간(예: 해당 학기 종료 시), 운영 위치
- 개인정보 보호책임자와 담당 교사의 이름·연락처
- 동의하지 않는 학생의 대체 신청 방법(예: 종이 신청서)

## 내기 전에 꼭 맞춰야 하는 것

서류에 적은 내용이 실제와 같아야 합니다. 지금 서류와 실제가 다른 곳은 다음 세 가지입니다.

1. **HTTPS**: 처리방침 제9조에 "전송 구간은 HTTPS로 암호화"라고 적었습니다. `TLS_CERT`·`TLS_KEY`로 HTTPS로 열거나 HTTPS 프록시 뒤에서 운영해야 사실이 됩니다.
2. **접속 주소와 처리방침 주소**: 체크리스트에 둘 다 적어야 합니다. 처리방침 주소는 교사 화면 위쪽 "개인정보"에 나옵니다(`/privacy/…`). 다만 찜콩은 학교마다 설치해 쓰는 방식이라, 에듀집 담당자가 열어 볼 수 있으려면 학교 밖에서도 접속되는 주소로 운영해야 합니다.
3. **보유 기간과 파기**: 자동 삭제 기능은 없습니다. 적은 기간이 지나면 담당 교사가 모집을 직접 지워야 합니다. 작업 기록도 자동으로 지워지지 않습니다.

## 확인이 필요한 것

- **대상 여부**: 정규 교육과정에서 학생 개인정보를 처리하면 대상입니다. 방과후 수업·일시적 평가용은 제외된다고 보도되었습니다. 동아리·자유학기 신청이 어디에 해당하는지는 학교·교육청에 확인하십시오.
- **개인 교사의 제출 경로**: 에듀집은 공급자(기업) 등록이 기본입니다. 사업자가 없는 교사 개인은 별도 구글 폼으로 낸다는 안내가 있으나 개인 저장소의 설명이라 에듀집 공지에서 확인해야 합니다.
- **공식 양식**: 체크리스트 문구는 다른 교사가 2026년 2월에 낸 공급자용 체크리스트와 똑같이 맞췄습니다. 에듀집에서 최신 양식(HWP)을 받아 옮겨 적는 것이 안전합니다. 동의서도 학교·교육청 양식이 있으면 그쪽을 쓰십시오.
- **심의 완화**: 검증된 소프트웨어는 학운위 심의를 면제하는 개정안이 보도되었습니다. 시행 여부를 확인하십시오.
- 에듀집에 올린 뒤 상태는 확인중 → 보완요청 또는 확인완료로 바뀝니다.
